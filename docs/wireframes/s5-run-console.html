灰色の箱は部品の位置と中身を示すだけで、色・余白・文字の大きさは実装時に既存画面（ガラス調・ライト/ダーク・5配色）に合わせます。赤い番号は、凡例の項目と、末尾の「確認したい点」に対応します。ここに描いていない画面や操作は作りません。

このワイヤーフレームの範囲: 新しい画面「実行」（/run）、ロボット設定への2項目の追加、シーン画面の導線、展示画面での停止中の扱い。進行時計・退避・異常時の処理そのものは設計書（8章）のとおりで、ここでは「画面にどう見せ、何を操作できるか」だけを決めます。

W10　画面の使い分け（既存の「制御」画面の自動ルートとの切り分け）

やりたいこと使う画面動かし方測位対象のロボットほかの方法との同時利用
手で操縦する制御（/control）の個別制御・複数制御人が操作（前進・後退・旋回・PWM）不要選んだ機体（手動モード）シーン実行中は操作できません
簡易デモ（時間どおりに合流する決まった動き）制御（/control）の「自動ルート」（いまのまま残す）時間だけで動かす（開ループ）不要自動モードにした機体シーン実行中は開始できません
編集したシーンを実行する実行（/run）（新規）測位で補正（閉ループ）＋完了待ち＋退避必須シーンの行に割り当てたロボット（開始時に自動で制御を引き継ぐ）手動操作・簡易デモの実行中は開始できません
非常停止ヘッダーの「全台停止」（全画面共通）すべての方式を止める—全台いつでも。シーン実行は「停止中（全台停止）」になり、再開か中止を選ぶ

決まったこと（回答をワイヤーフレームに反映済み）

  1. 到着待ちの時間切れ: 一定時間（初期値30秒、設定可）で「停止中（理由: 到着待ちの時間切れ）」にして、再開か中止を待つ（W3）。
  2. 展示との連動: 実行中は展示画面の時刻＝進行時計。実行していないときだけ、手動の展示再生を使える（W8）。
  3. 展示画面の停止表示: 案B（下中央に小さく表示）に決定（W9）。
  4. 結果: 画面に表示し、「結果を保存」で JSON をダウンロード。サーバーへは自動保存しない（W5）。
  5. 実行中の編集: 禁止（W8の帯のとおり、シーン画面は読み取り専用になる）。

追加で確認したい点（切り分けの整理のため）

  1. (A) 画面の使い分け（W10）: 簡易デモは「制御」画面にそのまま残し、排他の判定と案内だけ足す案（推奨）／簡易デモを「実行」画面のタブへ移す案。
  2. (B) ロボットの制御の引き継ぎ: シーンの実行を開始すると、対象のロボットを自動で「自動モード」にして制御を引き継ぎ、終了・中止で「手動モード」へ戻す（推奨）／事前に「制御」画面で自動モードにしておく。
  3. (C) シーンに入っていないロボットが盤面にいる場合: 実行前の確認で警告し、動かない障害物として扱う（推奨）／確認の ✗ にして開始できなくする／無視する。
  4. (D) 初期位置へ自動で動かす（W2）: 回答では「自動で動かす」を選ばれました。この場合に必要になる動きの範囲を決めさせてください（W2の下部の案）。
